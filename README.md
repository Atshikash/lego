# Coffre à Briques

Appli de collection LEGO d'Eddy et Cécile, installable sur téléphone : sets par thème, statut d'achat, cote et plus-value, minifigs, envies, pièces détachées, import et export CSV.

En ligne : https://atshikash.github.io/lego/

Les données restent sur chaque téléphone. « Compléter depuis le numéro » utilise l'API Rebrickable, avec une clé gratuite à saisir dans les réglages de l'appli.
